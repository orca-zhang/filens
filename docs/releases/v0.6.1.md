FiLens **v0.6.1** includes CLI **0.5.1**, Browser Preview **0.3.1** and mobile source SDKs **0.1.1**. The CLI bundles include the current offline preview runtime; file parsing and conversion share the frontend WASM core.

## Changes

- Preserve video position, play/pause state, volume, mute and playback speed when optional browser recovery switches from native playback to MSE. This adopts the useful playback handoff behavior reviewed in share-front without adding runtime dependencies. Bounded Range reads and binary-search keyframe lookup were already present in the shared Media Engine.
- Improve HEIF color handling, including 10/12-bit and HDR-related metadata paths, and expose optional local MP4/MOV recovery through `browserMedia: true`. Native playback remains the first attempt.
- Improve dual-fisheye panorama registration, polar handling and seam visibility, and refresh the CLI file-walker resource.
- Compact standalone JavaScript while retaining its existing chunk graph. Compress CLI WASM resources at gzip level 9. Replace huge generated iWork literal declarations with interface types; omit debug maps from production module tarballs while retaining local maps.

## Size changes

Compared with the published v0.6.0 artifacts, the preview npm download changes from **6.98 to 7.14 MiB (+2.3%)**, while installed files decrease from **21.72 to 20.40 MiB (-6.1%)**. The all-in-one browser ZIP is **3.58 MiB**, with **9.00 MiB** extracted files (-7.4%). Mobile SDK downloads are **3.59 MiB** each, with extracted files down about 5%. Compressed downloads still grow because of the HEIF and optional media additions.

Against the same current source before this optimization review, the preview download is **4.3% smaller**, installed files **11.3% smaller**, and all-in-one JavaScript **14.5% smaller**. The iWork package files (excluding transitive dependencies) shrink from **9.95 to 3.52 MiB** installed (-64.6%). CLI Lite/Full installed packages save about **0.19 MiB** per platform.

## npm availability

`filens-cli@0.5.1`, `filens-cli-lite@0.5.1`, `filens-preview@0.3.1` and all eight platform components are publicly available. Their registry integrity matches the tested tarballs. Fresh-cache public registry Full/Lite installation, OCR and first-use preview tests passed; the public preview package also passed the complete browser and TypeScript consumer checks. [Publication observations](https://github.com/IceWhaleTech/filens/blob/main/docs/npm-publication.json).

```sh

# Or: npm install -g filens-cli-lite@0.5.1

``` The exact tested preview tarball is available directly from this Release:

The 18 new `@filens/*@0.1.0` format modules are packed and checked, but publishing requires the `filens` npm organization and permission for the release account. The existing `filens-step@0.1.0-rc.1` is unchanged.

- Real Chromium media checks cover native playback, native-to-MSE continuity for paused/playing sessions, bounded Range reads, paused seeking, offline Blob playback and resource cleanup. Release privacy and size gates passed.
- No new physical-device or full native mobile SDK build validation was performed for this patch. Format fidelity and codec/device support follow the [support matrix](https://github.com/IceWhaleTech/filens/blob/v0.6.1/docs/support-matrix.md).
