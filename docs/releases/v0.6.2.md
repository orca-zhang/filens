FiLens **v0.6.2** adds the **DeepSeek Harness plugin 0.1.0**, alongside CLI **0.5.2**, browser preview **0.3.2**, `@filens/model3d` **0.1.1** and refreshed mobile source SDKs **0.1.2**.

## New: DeepSeek Harness plugin

`dsh-filens` installs five Agent tools and a multi-format sidebar renderer together; each can be enabled independently. Tools cover capacity, reading/OCR, directory and archive search, original excerpts and conversion. Preview uses DSH's Session file-read service and the shared frontend runtime, registering 397 extensions including conversion-assisted previews. This is the registration count, rather than 397 individually validated formats.

```sh
dsh plugin --profile desktop add dsh-filens@0.1.0
# Web profile:
dsh plugin --profile web add dsh-filens@0.1.0
```

Restart Desktop after installation. The universal plugin tarball includes the client, WASM, archive worker and notices; npm installs the matching CLI/OCR platform dependencies and models. Keep optional dependencies enabled. Tested on macOS arm64 with Desktop/Web **0.2.1-rc.5** and Web **0.2.2-alpha.3** (Node >=24.9). Other DSH versions remain unverified.

The sidebar fills its pane and follows DSH's palette, fonts and language. Loading identifies the file; parser failures offer details and retry; password-protected PDFs remain interactive. 3D previews have no top toolbar, fit the whole model in narrow panes, and support drag, scroll and double-click reset. Word pages fit the pane width while retaining reading position on resize.

## CLI and shared preview changes

- CLI input copies, WASM conversion results and PDF/OCR intermediate images now use a bounded memory workspace by default. Parallel workers share a **512 MiB file-data quota** with no automatic disk fallback. WASM linear memory, native OCR memory and transport copies are separate allocations; operating-system swapping is outside this setting.
- Select disk scratch explicitly with `--workspace disk` or stdin JSON `"workspace":"disk"`. Final conversion outputs and exported preview HTML still require write permission. The new CLI requires its matching byte-input OCR platform package; all four platform pairs are updated together.
- `hdrw.wasm` exchanges options and results through **stdin/stdout**, without option/result files or a `/work` mount. Its read-only input mount is `/scan`; the transport has bounded input/output buffers.
- Shared 3D camera fitting accounts for the narrower field of view in portrait or landscape panes, preserves user orbit and zoom on resize, and adds double-click reset. The fixes ship in both standalone browser builds and the DSH renderer.

```sh
npm install -g filens-cli@0.5.2
# Or: npm install -g filens-cli-lite@0.5.2
npm install filens-preview@0.3.2
npm install @filens/model3d@0.1.1
```

## Validation and limits

- Shared 3D: **326 tests** across 10 files. CLI Rust: **20 native tests and 22 WASI-walker tests**. Plugin: **7 test groups**, plus **12 formats and 13 interaction checks** in Chromium.
- Final CLI npm Full/Lite tarballs passed isolated installation, native OCR, stdin JSON, conversion, nested archive access and first-use preview checks. **23 workspace checks** passed against the packaged macOS binary, including a sandbox denying scratch writes, explicit disk mode and disk cleanup.
- Final preview tarball passed public declaration checks, **48 browser previews**, HEIF reference-pixel checks, media checks and both exports after production Vite bundling. Mobile runtime/bridge: **22 Chromium/WebKit checks**.
- Real DSH Desktop opens DOCX, Keynote, STEP and ZIP through its Session file service. Web integration covers the tool pipeline, read-only policy, independent lifecycle and package removal on both tested versions. No model prompt or DSH account was used.
- Release archives pass integrity, size and privacy checks. Native Windows/Linux execution and physical mobile devices were not validated in this release. See the [support matrix](https://github.com/IceWhaleTech/filens/blob/v0.6.2/docs/support-matrix.md) for format and codec limits.
