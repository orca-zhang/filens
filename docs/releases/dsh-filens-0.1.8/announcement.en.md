# FiLens for DSH: your session files, together

FiLens now has a separate **File workspace**. Browse documents, images and models grouped by conversation, open real previews, explore related files, and jump back to the message or question they came from.

Office files get rendered thumbnails. Other files retain clear type covers, temporary lock files stay hidden by default, and a compact reader keeps file details close at hand.

The native sidebar preview remains available, with an independent workspace switch. Parsing and previewing run locally.
