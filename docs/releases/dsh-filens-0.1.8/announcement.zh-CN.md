# FiLens for DSH：会话文件有了自己的工作台

这次给 FiLens 加了一个独立的「文件工作台」。会话中引用的文档、图片和模型会按会话聚在一起，封面直接显示缩略图；打开后能查看相关文件，还能跳回文件所在的消息和原提问。

Office 有真实缩略图，没有缩略图的文件也有清晰的类型封面。临时锁文件默认隐藏，文件信息面板和阅读列表也做了整理。

原有侧栏预览继续保留，工作台可以单独开关。解析和预览在本地完成。
