## What's new

Compared with [v0.6.3](https://github.com/IceWhaleTech/filens/releases/tag/v0.6.3), FiLens expands browser previews from **402 to 450 extensions** and CLI inputs from **334 to 349 formats**, reduces format-specific startup work, and improves repeated document previews and local search. Parsing and conversion remain in the shared frontend/WASM core.

Components: **CLI 0.5.6**, **browser preview 0.3.4**, **iOS/Android source SDKs 0.1.4**, **DSH plugin 0.1.3**, and updated `@filens/*` modules. The CLI and browser counts describe different capabilities; inspect `filens capacity --full --json` for each CLI operation.

### Formats and features

- Add **`filens inspect FILE --json`** to identify actual file content independently of the filename, with MIME, evidence categories and extension-mismatch reporting. The shared WASM detector reads at most **256 KiB**; large inputs are not copied into the temporary workspace. Ambiguous text/containers and unknown binary remain explicit. Detection evidence does not imply full-file validation. Refresh the English/Chinese terminal GIFs with an actual renamed-file inspection.

- CLI reading, OCR, excerpts and directory/archive search now accept **TGA, DDS, DIB, CUR, PCX, JPEG XL, QOI, Farbfeld, PSD, PSB, ICO, ICNS, AI, EPS and PS** through the existing shared WASM decoders. Photoshop uses saved composites; AI uses PDF-compatible artwork or the PostScript interpreter; raster-only artwork requires OCR for text. Existing image and design conversions are also available in the CLI build.
- Add TIFF, TGA, PBM/PGM/PNM, DDS, HDR, DIB, CUR, PCX, EXR, JPEG XL, QOI and Farbfeld previews, plus DWG-to-DXF 2D preview. The optional graphics engine loads on first use. TIFF displays the first usable image; HDR/EXR previews use 8-bit output. See the [support matrix](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/support-matrix.md).
- Expand archive browsing and nested opening to BZip2, XZ, LZMA, Zstandard, Unix compress, LZMA86, compound TAR extensions, AR/DEB, CPIO, CAB, ISO/UDF, RPM, XAR, WIM/ESD and LHA/LZH, including WIM multi-image directories and UDF images named `.iso`.
- Add XPI, CRX2/CRX3, ZIPX with BZip2/Deflate64/LZMA entries, and CBR/CB7/CBT containers, using actual readers for their contents.
- Archive browsing gains name filtering, name/size/date sorting, empty-state messages, arrow-key navigation, Enter/Space to open, and Escape to clear filtering. Returning from a preview restores the query, scroll position and keyboard focus.
- Add the optional `@filens/converter-client/format-detector` export. Importing it does not fetch WASM; instance creation loads the selected SIMD/scalar artifact. SIMD download, compilation or initialization failure falls back to the scalar build.
- Expand image, code/text, archive and system-package examples. Remote opening handles encoded URLs, signed query strings, explicit filenames for extensionless URLs, same-origin relative paths, and browser history.
- DSH mounts previews directly in the sidebar DOM and uses the outer DSH zoom/fullscreen toolbar. Update the installation/Office demo and retain the 3D/panorama gallery and historical benchmark evidence.

## Performance improvements

### Loading, compression and package size

- Load preview drivers by format, separating routing metadata from renderers. Share pending and successful imports. Text/PDF no longer preload Office, iWork, CAD or Three.js; nested files and conversion outputs follow the same routes.
- In the DSH loading comparison, entry JavaScript fell from **3.04 MiB to 345 KiB**, about **89%**; TXT first-open runtime requests fell from **3.09 MiB to 449 KiB**. These are requested raw runtime bytes, excluding the input file. [Measurements](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/assets/dsh-plugin/format-loading.json).
- Load the DOCX engine, JSZip compatibility reader, encrypted-ZIP reader and OLE attachment reader only when needed.
- Load GLB/glTF, OBJ/MTL, USDZ, LDraw, FBX, 3DS and WRL/VRML engines for their respective formats. FBX, 3DS and VRML have separate chunks; public synchronous loader APIs remain available. The all-in-one build still embeds every engine. [Media/readers](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/media-loading-performance.zh-CN.md), [FBX/3DS](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/fbx-3ds-loading-performance.zh-CN.md), [VRML](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/vrml-loading-performance.zh-CN.md).
- Reuse fflate for JSZip DEFLATE encoding and Pako for ZIP/TIFF decoding, removing duplicate production codecs while retaining metadata, CRC and decompression errors. [Compression](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/shared-compression-performance.zh-CN.md).
- Pack shared WASM, workers, CSS and large static data into the all-in-one runtime, with supplied gzip/Brotli representations of the main JS verified at **no more than 4,000,000 bytes each**. Archive sidecars, HTML, notices and the complete npm package are measured separately. Initialization includes decoding work. [Delivery and startup tradeoffs](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/preview-4mb-performance.zh-CN.md).
- Exclude source maps from published frontend packages and remove invalid declaration-map references. Local builds retain hidden maps. This reduces package download/extraction bytes rather than claiming equivalent runtime-JS savings. [XLSX](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-compact-performance.zh-CN.md), [core/archive](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/shared-readers-performance.zh-CN.md), [other packages](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/viewport-fonts-packaging-performance.zh-CN.md).

### ZIP, XML, media and resources

- Share ZIP directory indexes, lazy decompression and bounded entry caches across EPUB/CBZ, XMind/MindManager, Visio and 3MF. Retain ZIP64 and legacy Unicode compatibility; an unused attachment's unusual compression no longer forces a complete PPTX ZIP rescan.
- Inflate large ZIP entries directly into the destination buffer, reducing intermediate chunks and concatenation. Ordinary resource paths bypass repeated normalization; actual dot segments retain normalization. [ZIP reader](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/zip-performance.zh-CN.md).
- Use the fast OpenXML parser for ordinary PPTX; load the general XML parser for syntax such as special entities. Load it after recognizing XLSX, and skip it for CSV. Remove unused XMLBuilder code from production previews and reduce temporary PPTX node arrays. [XML](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xml-formula-performance.zh-CN.md), [shared readers](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/shared-readers-performance.zh-CN.md).
- Avoid an extra full byte copy when creating media Blob URLs, and share the preview/download URL. Shared buffers still use snapshots. Prefer native byte-to-Base64 APIs with bounded fallback chunks across media, EPUB and 3D textures.
- Stop TIFF preview decoding after the first valid image with usable dimensions and pixels, avoiding work on undisplayed pages. Full-conversion validation remains separate. [TIFF](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/shared-compression-performance.zh-CN.md).
- Read only referenced EPUB resources and scan CSS URL/import candidate tokens. Find direct MindManager topics in wrapper order without repeated descendant walks; skip unnecessary attributes on invisible Visio containers while still parsing child shapes. [Document resources](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/document-resources-performance.zh-CN.md).
- Reuse normalized uploaded-resource paths, root aliases and basename candidates, preserving exact-path priority and duplicate-name ambiguity. Build KMZ case-insensitive and unique-suffix indexes only when a fallback is needed. [Resource indexes](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/text-layers-resources-performance.zh-CN.md), [KMZ](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/batch-matching-performance.zh-CN.md).
- Share extension/MIME indexes for default format routes, preserving first-rule and extension priority. Custom rule arrays remain live; callers can explicitly create a snapshot index.
- Reuse archive name ordering, recompute size/date ordering only when options change, and filter sorted results. Keyboard movement uses adjacent result rows instead of collecting the entire DOM list.

### XLSX parsing, formulas and reopening

- Build cell models directly for numeric/shared-string sheets, including supported column styles and simple `sheetData` attributes. Cache styles for accessed columns and move row defaults outside cell loops. Complex XML, rich text and formulas retain the general-parser fallback. [Columns](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-column-performance.zh-CN.md), [XML fast path](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-xml-performance.zh-CN.md).
- Reuse attribute/numeric matchers, retain only used cell attributes, and reduce repeated property wrappers, column-name conversions and range-bound parsing.
- Resolve formula dependencies by row/column coordinates. Build bitmap indexes directly for ordered sheets; sort a private index for unordered inputs, retaining last-declaration semantics for duplicate coordinates. [Cell indexes](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-cell-index-performance.zh-CN.md), [compact indexes](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-compact-performance.zh-CN.md).
- Evaluate ranges over existing cells and use contiguous data for complete rows. Stream `SUM` accumulation without temporary range arrays or a second pass, retaining argument order, overflow, circular-reference and error behavior. [Streaming formulas](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/xlsx-streaming-performance.zh-CN.md).
- Reuse recently parsed workbook models to skip repeated ZIP/XML parsing. Tabs receive independent cells/fonts; formula evaluation and font mapping cannot contaminate subsequent opens. CSV keeps direct parsing, and public parser calls still parse each input.

### PDF first page, scrolling and reopening

- Reveal a document when its first page has actually painted; render nearby pages in the background. Nonvirtual print/export still waits for complete rendering. DSH removes the PDF loading overlay in the same frame.
- Locate visible pages with ordered page slots and binary searches over actual DOM geometry. Cancellation/release visits only pages with active canvases/tasks. [Viewport lookup](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/viewport-fonts-packaging-performance.zh-CN.md).
- Reuse an independent snapshot of the complete first-page pixels for recent reopens, keyed by full-file SHA-256, exact CSS viewport and canvas resolution: **4 pages, 16 MiB, 30-second idle expiry**. Password, URL and nonvirtual print paths bypass the cache. Every open still loads/validates the PDF; closing releases documents, workers and active canvases. [Implementation and checks](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/assets/dsh-plugin/pdf-reopen-optimization.zh-CN.md).

### iWork, fonts, CAD, SVG and 3D

- Index iWork text styles and Pages paragraph/inline-attachment positions with ordered ranges, preserving duplicate positions, empty-style inheritance/reset and malformed-position fallbacks. [Text indexes](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/text-layers-resources-performance.zh-CN.md).
- Reuse normalized font names and glyph state while collecting fonts; stop accumulating after the sample limit. Font diagnostics reuse classification within one call but return independent objects and recompute across calls. [Font pipeline](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/viewport-fonts-packaging-performance.zh-CN.md).
- Maintain a document-local CAD layer-name set for bulk/single-layer selection, synchronized on replacement, cancellation, failure, redraw and destruction.
- Share delegated SVG events and ID indexes for mind maps/diagrams; selection updates only previously/newly selected nodes. Preserve keyboard navigation and duplicate-ID highlighting; detach old handlers on page changes/destruction. [SVG selection](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/svg-selection-performance.zh-CN.md).
- Share texture lookup and scene-finalization work across five 3D loaders, preserving resolution priority, warnings, camera state and object-URL cleanup.
- Reuse parsed Pages/Keynote models without starting a parsing worker on cache hits. Numbers still starts with the first sheet and restores archive context only when another sheet is requested after reopening.
- Reuse CPU meshes from STEP's WASM conversion while recreating independent geometry, materials, scenes and GPU resources per tab. Direct public `loadStepObject` calls default to conversion; previews explicitly enable short-term reuse.
- Share a **4-entry, 64 MiB estimated model budget, 30-second idle-expiry** LRU across XLSX/iWork/STEP. Retain data snapshots only; closing still releases DOM, URLs, workers and GPU resources. Password-based opens, including decrypted Office outputs, bypass reuse. Full-content digests invalidate changed files. [Model cache and costs](https://github.com/IceWhaleTech/filens/blob/v0.6.4/docs/assets/dsh-plugin/model-reopen-optimization.zh-CN.md).

### CLI search, OCR and content detection

- Determine exact-search body matches using the current file's result boundary instead of rescanning previous files' blocks; skip tokenization unused by exact-mode scoring.
- Accumulate BM25 document frequency by query-term ID and calculate IDF/query weights once. Reuse normalized body/filename phrase checks and use a lowercase fast path for ASCII.
- Store query features in compact ordered numeric lists and extract filename frequencies on demand. Count body block lengths/query frequencies directly instead of building complete dictionaries for unrelated words. Borrow normalized UTF-8 slices to reduce temporary word/Chinese-bigram allocations.
- Select the best result files before sorting their candidate excerpts, preserving matched-file totals, stable ranking, up to three nonoverlapping excerpts and source offsets.
- Add SIMD ASCII detection, lowercasing and separator scanning to the shared search core: optional SIMD128 in browsers, SSE2/NEON in native CLI, scalar fallback elsewhere. Mixed Unicode retains the NFKC path; execution errors do not silently retry operations.
- Index OCR score records by line after one scan, Office media by slide path/first reference, and page selections with ordered lookup. Retain output order and score semantics.
- Preserve Chinese/Unicode tokenization, numeric-token thresholds, BM25 floating-point operation order, ranking, excerpts and source mapping. ## Bug fixes and compatibility

- **RAR/7z after production bundling:** copy archive WASM/worker resources when a Vite consumer rebundles the all-in-one npm export, preserving reachable resource URLs.
- **Large `SUM` ranges:** remove function-argument spreading; a 160,000-cell range works while preserving floating-point order, intermediate overflow and error short-circuiting.
- **Unicode EPUB styles:** encode strings as UTF-8 before Base64 inside opaque-origin frames, avoiding direct `btoa` on Unicode strings.
- **HEIF colors and auxiliary images:** fix 10-bit Apple-edited HEIF and grid/nested-grid color-metadata inheritance; follow image-tile relationships without treating alpha, thumbnails or tone maps as RGB configuration. Add P3, linear-ICC and alpha regressions.
- **10-bit HEVC 4:4:4:** update chroma decoding and verify reference pixels.
- **Unused ZIP attachments:** defer unsupported-compression errors until the affected attachment is actually read, allowing supported document parts to open.
- **ZIP sizes and cancellation:** reject mismatches between declared size and actual decompressed output; check cancellation even on cached reads.
- **Malformed images and optional engines:** validate decode bounds before dimension access; reject truncated PCX rows and invalid CUR directories; report the required optional graphics module explicitly.
- **TIFF later-page corruption:** a corrupt undisplayed page no longer prevents previewing an already decoded valid first image; full conversion keeps its validation.
- **Remote loading/workbench state:** clear stale previews after download failure while retaining the attempted source; ignore late remote responses after local selection; restore matching sources through browser history. Late route imports no longer override manual category selection.
- **Stale asynchronous results:** strengthen cancellation/generation checks for reading, dynamic imports, parser workers and rendering; release old scenes, textures, URLs and events on replacement/destruction.
- **Archive focus/events:** fix focus, scroll and empty states after filtering/sorting/returning; detached lists, SVGs and controls cannot mutate the active document.
- **Published type imports:** retain the `@filens/media` package reference in Vue declarations instead of repository sibling paths; remove broken source-map references from published/copied declarations.
- **Direct DSH mounting:** handle Desktop cross-origin modules/WASM, Blob workers and shared-style lifetimes. Pass copied source bytes so worker transfer cannot damage the host's retained file; isolate tab controls and destruction.
- **Cache correctness:** prevent cross-tab font/formula contamination, stale reuse after same-name edits, wrong PDF resolution after viewport changes, missing Numbers archive context on later sheets, and shared STEP geometry/material destruction. Cache failures return to normal parsing/rendering.
