# README visuals

- `highlights.{zh-CN,en}.svg` and their PNG exports are project-authored banners using the FiLens logo's cyan, violet and pink palette on a pale gradient panel, under the project's MIT license. The desktop banner displays all four capabilities in one 640×112 image. `highlights-mobile.{zh-CN,en}.svg` and PNG use a 320×224 two-column layout, selected by the README's `<picture>` element at viewport widths up to 600 pixels. PNGs are rendered at twice the display resolution. Edit the SVG text directly and export with `rsvg-convert --zoom 2 --output TARGET.png SOURCE.svg`; the sources contain no scripts or external resources. Capabilities and comparison scope are documented in the linked overview.
- `overview.webp` uses a pearl gradient background, translucent cards and file badges in the FiLens logo palette. It combines twelve actual filens preview captures (PPTX, DOCX, XLSX, PDF, Keynote, DXF, the project-authored Viking helmet OBJ, panorama, video, music, ZIP archives, and EPUB ebooks) and locally drawn file badges in a four-column, three-row grid. It includes cropped, pale-blue aurora photography by **Carsten** (CC BY 2.0), a perspective view of **Greg Zaal / Poly Haven**'s Rogland Clear Night (CC0), the **MDN** flower video (CC0), the public-domain **NASA, ESA, CSA, STScI** Cosmic Cliffs music cover, and a cropped panel from **David Revoy**'s **Pepper & Carrot**, episode 1, “The Potion of Flight” ([source](https://www.peppercarrot.com/en/webcomic/ep01_Potion-of-Flight.html), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); English proofreading by Amireeti and Alex Gryson). The composite is distributed under CC BY-SA 4.0.
- `demo.gif` is a resized, accelerated derivative of the project's actual screen recording, including zooming and orbiting the Viking horned helmet, distributed under CC BY-SA 4.0. Both READMEs link to the full-speed MP4 with translated captions.
- `preview.gif` and `dsh-preview.{en,zh-CN}.gif` add a gradient frame in the FiLens logo palette to `demo.gif` and the original DSH Office recordings. Source UI, captions and playback duration are preserved; frames are sampled at 12 fps. The DSH footage remains the documented 0.1.10 capture, including the introduction deck as it appeared then. Regenerate with `node scripts/frame-readme-demos.mjs`; source paths are recorded in `demo-frames.json`. The browser recording retains CC BY-SA 4.0; DSH source credits remain in [its source list](../dsh-release/README.md).
- The two [FiLens-Bench summary SVGs](../../../benchmarks/filens-bench/) use pale panels and gradient bars to distinguish FiLens from the baseline.
- `zimaos-banner.zh-CN.png` and `zimaos-banner.en.png` are compact, project-composed promotional banners using the [official ZimaOS logo](../../../apps/demo/public/brand/SOURCES.md). The resized logo sits on a pearl gradient panel with a cyan, violet and pink button. These banners are separate from the preview composites' CC BY-SA license; the ZimaOS brand belongs to IceWhale. Regenerate them with `python3 scripts/generate-zimaos-banners.py` (requires `rsvg-convert` from librsvg and a Chinese sans-serif font such as PingFang SC or Noto Sans CJK SC). Each PNG is rendered at 1280×256 and displayed at 640×128 in its README.
- The document is a fictional polar field guide; the workbook contains fictional observation data. The aurora is artistically color-graded, while the 360° source is a complete equirectangular Milky Way panorama.

Photo links, licenses, preparation steps, document provenance, and recording details: [homepage visual sources](../../../apps/demo/public/home/SOURCES.md).

Regenerate the captures first, then run `node scripts/generate-readme-assets.mjs`. Then run `node scripts/frame-readme-demos.mjs` to refresh the framed animations. The scripts require Playwright Chromium and FFmpeg. Both language versions use the same preview visuals; ZimaOS banners have localized copy.

To refresh only the overview's video, music, archive, and ebook previews, run `node scripts/capture-homepage-demo.mjs --readme-only` with the demo server running, followed by `node scripts/generate-readme-assets.mjs --overview-only`. These options preserve the walkthrough and animated preview and require only Playwright Chromium.

README banner links use `utm_source=github`, `utm_medium=referral`, `utm_campaign=filens_zimaos`, and `utm_content=readme_banner_zh` / `readme_banner_en` to distinguish the two languages. Their destinations remain the matching Chinese and English ZimaOS product pages.
