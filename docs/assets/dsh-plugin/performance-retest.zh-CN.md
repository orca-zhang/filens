# DSH 0.1.3 性能复测（PDF 像素缓存优化前）

后续 PDF 优化与最新计时见 [PDF 重复打开优化](pdf-reopen-optimization.zh-CN.md)。本文保留优化前的完整样本。

2026-11-05，使用当前按格式加载的 **dsh-filens 0.1.3 候选包**重新测量。
对比已发布 **0.1.2** 与 DSH 的实际内置预览。每种格式 **9 个完整配对轮次**，
共 **54 次桌面进程启动、324 次文档打开**；本轮没有失败、重试或排除任何已计时样本。

| 格式 · 首开 / 重复打开中位数（ms） | 0.1.2 | 0.1.3 候选版 | DSH 内置 |
| --- | ---: | ---: | ---: |
| PPTX | 535 / 311 | **135 / 81** | 1830 / 124 |
| DOCX | 294 / 278 | **111 / 94** | 1827 / 112 |
| PDF | 682 / 444 | **220 / 159** | 331 / 111 |

首开指该文件在每个新 DSH 进程中的第一次打开，不包含应用启动时间。
“重复打开”每个进程测 3 次，汇总 27 次耗时的中位数；每次都关闭文档标签后再打开。
PDF 在独立进程中首先打开；Office 进程按 PPTX、DOCX 顺序打开，所以 DOCX 会复用已初始化的宿主。
插件计时等待实际内容 ready 加两帧；内置等待可见 PDF canvas 加两帧。
PDF 使用内置 PDF 预览，Office 使用实际的内置 Office 转 PDF 流程。没有模型调用。

## 与 0.1.2 的差异是否超出波动

| 格式 | 首开：中位数速度比 / 耗时减少 | 配对减少比例 95% 区间 | 重复打开：中位数速度比 / 耗时减少 | 配对减少比例 95% 区间 |
| --- | ---: | ---: | ---: | ---: |
| PPTX | 3.96× / 减少 74.8% | 74.2%–76.3% | 3.84× / 减少 74.0% | 70.1%–74.2% |
| DOCX | 2.65× / 减少 62.2% | 60.1%–62.6% | 2.96× / 减少 66.2% | 66.2%–66.5% |
| PDF | 3.10× / 减少 67.7% | 66.8%–68.8% | 2.79× / 减少 64.2% | 63.8%–65.5% |

速度比为旧版中位数 ÷ 新版中位数。区间按完整轮次配对重采样（20,000 次，固定随机种子），
重复打开使用每轮 3 次的中位数，避免将同进程的 3 次打开当作独立轮次。
区间估计的是“逐轮耗时减少比例的中位数”，与汇总中位数之比是不同统计量。
三个格式的首开与重复打开，在全部 9 轮中均快于 0.1.2；本轮观察到的收益明显超出轮间波动。

相对 DSH 内置，PPTX 与 DOCX 的首开和重复打开在本轮中位数上均更快。
PDF 首开快约 **33.5%**，重复打开仍慢 **48 ms（43.2%）**。
此前“快 5–6.5 倍”不应作为当前版本跨格式的统一结论；应按上表分别写明格式、对照版本和缓存状态。

## 环境与边界

- Apple M4 Pro，12 核，24 GiB，macOS/Darwin 25.6.0；DSH Desktop 0.2.1-rc.5 / Electron 44.7.0，测试驱动 Node 24。
- 每轮按顺序轮换三种渲染器，每种渲染器新开进程；Office 与 PDF 分开执行。
- 使用独立临时 DSH 配置；保留系统文件缓存和持久缓存，没有清空 Office 转换缓存。因此结果不能解释为冷磁盘性能。
- 仅测试两份约 0.6 MiB 的自制 Office 文档与一份 PDF，结论限于这些样本；速度测试不评价渲染保真度。
- 测量期间没有并行执行构建、功能测试或视频编码。统计计算在所有计时结束后进行。
- 已逐文件核对测试安装与 tgz：0.1.3 共 75 文件、0.1.2 共 28 文件，全部相同。
- 上一次未完成 Office 测试的启动错误来自复制配置后凭据文件权限为 644；本轮在新隔离配置中修正为 600，运行时未改动。
- 未上传或重新打包插件；当前候选包仍等待用户确认。安装演示仍记录已发布 0.1.2。

测试使用仓库的 `scripts/benchmark-dsh-office-preview.mjs`。在准备好包含相应包的隔离配置后运行：

```sh
npx --yes --package=node@24 node scripts/benchmark-dsh-office-preview.mjs \
  --home /path/to/isolated-0.1.3-profile \
  --baseline-home /path/to/isolated-0.1.2-profile \
  --rounds 9 --output /path/to/office-report.json

npx --yes --package=node@24 node scripts/benchmark-dsh-office-preview.mjs \
  --home /path/to/isolated-0.1.3-profile \
  --baseline-home /path/to/isolated-0.1.2-profile \
  --rounds 9 --only-pdf --output /path/to/pdf-report.json
```

本轮为每个渲染器 / 每轮单独调用相同脚本（`--renderer`、`--rounds 1`、`--round-offset`），
由外层顺序执行、轮换顺序并设置每次 150 秒看门狗；没有触发看门狗。
原始报告保留了基准脚本、启动辅助脚本、两版入口和候选 tgz 的 SHA-256。
