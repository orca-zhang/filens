# Original archive samples

All packaged text and artwork is original Filens material under the repository's MIT license. Artwork comes from `../graphics/color-archive.jpeg` and `../graphics/shape-study.svg`.

- `color-study.xpi`: real ZIP-based extension package with a Manifest V3 manifest and SVG artwork.
- `color-study-v2.crx`, `color-study-v3.crx`: valid CRX2/CRX3 envelopes with RSA proofs, containing the same original extension. Preview reads the ZIP payload; it does not validate signatures or install extensions.
- `color-study-bzip2.zipx`, `color-study-deflate64.zipx`, `color-study-lzma.zipx`: ZIPX containers using three different compression methods supported by the existing WASM ZIP decoder. These are not renamed Deflate-only ZIPs.
- `color-study.cbr`: RAR5 comic archive, generated with the official RAR tool.
- `color-study.cb7`: LZMA2 7z comic archive.
- `color-study.cbt`: TAR comic archive.

Comic archives contain `page-2.jpeg`, `page-10.svg` and `README.md`. Their preview supports browsing and opening image pages, rather than the sequential CBZ book reader.

Regenerate with `node scripts/generate-more-archive-samples.mjs`. This uses the existing development-only `7z-wasm` package and an installed `rar` executable (or `FILENS_RAR_BIN=/path/to/rar`). The ephemeral extension signing key is discarded. RAR is used only for specimen creation and is not shipped or invoked by the application.

## Compressed streams and containers

Generated by `python3 scripts/generate-compressed-archive-samples.py` (Python 3, `zstd`, and macOS `hdiutil` are fixture-generation tools only):

- `archive-readme.md.bz2`, `.xz`, `.lzma`, `.zst`, `.zstd`: genuine standalone streams containing the same original README. Zstandard is generated without a declared content size.
- `color-study.tbz`, `.tbz2`, `.txz`, `.tlz`: genuine BZip2, XZ and LZMA compressed TAR archives containing the original README, JPEG and SVG.
- `color-study.ar`: Unix AR container.
- `color-study.deb`: Debian 2.0 package with `control.tar.xz` and `data.tar.zst`; the latter contains the artwork.
- `color-study.cpio`: SVR4 newc container.
- `color-study.cab`: Microsoft Cabinet with MSZIP compression, multiple data blocks and dictionary continuation.
- `color-study.iso`: ISO 9660/Joliet optical-disc image generated by `hdiutil makehybrid`.

All previews are read-only file browsing. These specimens are not installed, mounted or executed by the application.

## System/package archives and seasonal artwork

Generated by `python3 scripts/generate-system-archive-samples.py`. The new `field-notes` collection contains an original 900 × 540 SVG, **A year in four colors**, a JSON palette and a multilingual README, all under the project MIT license.

- `field-notes.md.Z`, `.bzip2`, `.lzma86`: Unix compress, BZip2 and LZMA86 streams. LZMA86 enables the x86 BCJ filter and recovers the original UTF-8 text.
- `field-notes.taz`, `.tzst`: Unix compress / Zstandard compressed TARs.
- `field-notes.lha`, `.lzh`: real LH5 / LH6 compressed LHA archives.
- `field-notes-zstd.rpm`, `field-notes-xz.rpm`: unsigned RPM 3.0 packages with SHA-256 file digests, header/payload MD5 and Zstandard / XZ CPIO payloads.
- `field-notes.xar`, `field-notes-bzip2.xar`: real XAR archives with zlib / BZip2 file compression and a compressed XML table of contents.
- `field-notes.wim`: LZX WIM. `field-notes-multi.wim` contains two separate images and a different README in the second image.
- `field-notes.esd`: solid LZMS WIM/ESD image.
- `field-notes.udf`: UDF-only optical-disc image; also validates UDF detection when the uploaded filename ends in `.iso`.

Fixture creation uses macOS `compress`, `xar`, `hdiutil`, plus `zstd`, [LHa](https://github.com/jca02266/lha) and [wimlib 1.14.4](https://wimlib.net/). Set `FILENS_LHA_BIN` and `FILENS_WIMLIB_BIN` for custom native tool paths. These native tools are not shipped or invoked by the application; runtime decoding uses the frontend WASM engine and shared frontend archive readers.
