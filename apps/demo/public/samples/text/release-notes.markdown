# 云笺 · Release notes

## 2.4.0 — 2026-10-24

本次更新围绕“更容易找到上次的灵感”。

### 新增

- 收藏夹支持多级标签，例如：旅行 / 城市 / 建筑。
- 阅读进度会在同一台设备上自动保存。
- 搜索结果可以按标题、日期和文件类型排序。

### 改进

| 场景 | 更新前 | 更新后 |
| --- | --- | --- |
| 夜间阅读 | 固定白底 | 跟随系统主题 |
| 长文导航 | 手动滚动 | 显示标题目录 |
| 键盘操作 | 部分入口可用 | 完整焦点顺序 |
