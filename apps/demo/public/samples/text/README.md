## 一个小练习

1. 找到一种重复出现的形状。
2. 用文字、线条、声音记录它。
3. 把观察写成一句 **具体的话**。

~~~json
{
  "theme": "patterns in everyday life",
  "durationMinutes": 30,
  "materials": ["paper", "pencil", "recorder"]
}
~~~

## 空间约定

请把工具放回原处；未经允许，不拍摄他人的作品。
分享时标注作者，引用时保留来源。
