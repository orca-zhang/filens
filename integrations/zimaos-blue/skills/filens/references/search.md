# Search details

## Find files and original evidence

Use compact text output for positive retrieval: `filens search '/path/documents' --query 'budget risk'`. The CLI defaults to text; omit `--json` and `--format json` unless structured fields are needed. For a machine-readable request, pipe `{"op":"search","input":"/path/documents","query":"预算 风险","format":"json"}`. Chinese and English quoted directory/query intents are supported. This is lexical BM25 with exact matching boosts, not embedding-based semantic retrieval. `--search-mode exact` matches case-sensitive literal text; `files` searches filenames without reading contents.

Use `--search-mode glob --query 'reports/2026/**/*.pdf'` for filename patterns. Quote the pattern. `*` and `?` match within one segment (`?` is one Unicode character); a whole `**` segment matches zero or more directories. Patterns without `/` match basenames anywhere; otherwise they match the full relative path using `/` on every platform. Matching is case sensitive; other characters are literal. Discovery prunes impossible subtrees and filters unrelated files before `maxFiles`; inspect `search.scan.prunedDirectories`. Basename-only patterns still enumerate all directories. Candidate archives remain eligible for member discovery, e.g. `'archive.zip!/**/*.pdf'`; archive expansion limits still apply.

Current builds support nested archive search. ZIP/JAR/WAR/EAR/APK, TAR, TGZ/TAR.GZ and GZ can be searched directly or discovered inside a directory, up to eight container layers. Members are independent search results with paths such as `/path/outer.zip!/inner.tar.gz!/report.pdf` and structured `archive.path` / `archive.members`. Use that virtual path with `read`, `layout` or `summarize` to retrieve the same member; offsets address that member's extracted text. Images and scans use the same OCR callbacks. Filename mode lists members without parsing their content or running OCR, although nested containers and sequential TAR/GZIP still need decoding. Limits, corrupt/encrypted members and OCR failures produce partial errors. RAR/7z and archive passwords are unsupported. Expansion uses generated flat temporary paths and is not a persistent extraction cache.

Inspect `search.complete`, `search.truncated`, `search.scan` and each result's `sourceComplete`. Errors and limits can leave usable evidence while returning exit 3. Zero lexical matches do not prove no relevant document exists. Results are ranked by file, with up to three original excerpts per file. `startByte/endByte` address the full extracted text returned by `read`, not the combined search response. `sha256` is null: search assumes source integrity and does not calculate a content fingerprint. Keep available page/coordinate evidence and `boundsScope`; geometry belongs to the source block and can cover more than the excerpt.

Default scope is 2000 supported files, depth 32, ten returned files; hidden names and `.git`, `node_modules`, `target`, `dist` are excluded. `--include-hidden` includes ordinary hidden names while the four excluded directories remain excluded. Subdirectory symlinks are not followed. Use `--max-files`, `--max-depth`, `--max-results` and `--timeout` to adjust scope and budget. Search keeps extracted text and ranking data only for the current request, with no persistent index/cache and no source/engine/OCR hashes. `sha256` is null and source integrity is assumed. `--no-cache` / `cache:false` are accepted; `cache:true` is unsupported. Each request discovers current files again, so edits/deletions are reflected immediately. Default retrieval and common plain-text decoding compile the same frontend Rust sources natively, without loading WASM; other formats/layout use the shared WASM parsers in bounded batches. `search.scan.execution` reports native files, module loads and workers. An explicit WASM override uses that module for extraction and ranking. macOS uses native FTS; Windows batches NTFS directory metadata with native traversal as fallback; Linux uses native traversal. No administrator privileges or raw device access are needed.
